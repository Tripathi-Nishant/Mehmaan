## Commands

Run after installing `uv` and copying `.env.example` to `.env`:

```bash
uv sync
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run python scripts/smoke_gnani.py path/to/hindi.wav
```

In this Windows environment, the equivalent verified commands were run as `py -3 -m uv ...` because the user-level `uv` executable directory is not on PowerShell's current PATH.
